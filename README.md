## 🚀 Quick Start - Production Deployment

### **One-Click Production Launch**

```powershell
# Windows - One-click launch (kills existing processes)
launch.bat

# Unix/Linux/macOS - Cross-platform launch
chmod +x launch.sh && ./launch.sh

# Python - Cross-platform launch (with port conflict handling)
python launch.py

# Check server status
python check_server.py

# Direct uvicorn launch
python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000
```

📖 **Detailed Launch Guide**: See [LAUNCH_GUIDE.md](LAUNCH_GUIDE.md) for comprehensive instructions, troubleshooting, and feature overview.

### **Production Environment Setup**

```powershell
# Activate virtual environment (if using)
venv_daena_main_py310\Scripts\activate

# Start production server with launch script
python launch.py

# Or start directly with uvicorn
python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000 --workers 4
```

## 🛠️ Development Setup

### **Prerequisites**
- Python 3.10+
- Node.js 18+
- PostgreSQL 14+
- Redis 6+
- Git

### **Installation**
```bash
# Clone repository
git clone <repository-url>
cd Daena

# Backend setup
cd backend
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows
pip install -r requirements.txt

# Environment configuration
cp .env.example .env
# Edit .env with your API keys

# Database setup
python manage.py migrate

# Start backend server
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```
